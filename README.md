# מצפן 🧭

אפליקציה אישית לטלפון שעושה סדר בחיים, במשימות ובנפש, ועוזרת להכיר את הכוחות והחולשות ולהתנהל טוב יותר.

**לפתיחה ולהתקנה:** https://roeokabe.github.io/matzpen/
(ב-Chrome באנדרואיד: תפריט ⋮ ← "התקנת האפליקציה")

## האלמנטים באפליקציה

| אלמנט | מה הוא עושה | קובץ |
|---|---|---|
| **היום** (צ'ק-אין) | מצב רוח, אנרגיה, שלושת הדברים החשובים ושאלות על היום, עם תובנה יומית מ-Claude | `js/checkin.js` |
| **משימות** | כתיבת משימות בשפה חופשית. Claude נותן שם קצר, נושא ודירוג, והרשימה מסודרת לפי עדיפות | `js/tasks.js` |
| **היסטוריה** | גרף מצב רוח ורשימת הימים הקודמים | `js/checkin.js` |
| **דפוסים** | ניתוח של עד 30 ימים: כוחות, חולשות ומה משפיע על מצב הרוח | `js/checkin.js` |
| **הגדרות** | מפתח API, גיבוי ושחזור, ומחיקת נתונים | `js/settings.js` |

## פרטיות

כל הנתונים נשמרים רק בטלפון. טקסטים נשלחים ל-Anthropic רק כשמבקשים תובנה או ניתוח, וכשמוסיפים משימה. מפתח ה-API נשמר רק במכשיר.

## מבנה הקוד

אפליקציית ווב פשוטה, בלי שלב בנייה (build): הקבצים בתיקייה הם בדיוק מה שהדפדפן טוען.

```
index.html            מבנה המסכים
styles.css            העיצוב
sw.js                 עבודה בלי אינטרנט (Service Worker)
manifest.webmanifest  שם, אייקון והתקנה בטלפון
js/main.js            הפעלה וניווט בין הלשוניות
js/nav.js             מעבר בין מסכים
js/db.js              שמירה במכשיר (IndexedDB)
js/claude.js          החיבור ל-Claude
js/util.js            פונקציות עזר משותפות
js/checkin.js         היום, היסטוריה ודפוסים
js/tasks.js           משימות
js/settings.js        הגדרות
```

## איך עובדים על הפרויקט

1. **רעיון או תקלה** נרשמים ככרטיס ב-[Issues](https://github.com/roeokabe/matzpen/issues), עם תווית של האלמנט.
2. **ההתקדמות** מנוהלת ב[לוח הפרויקט](https://github.com/users/roeokabe/projects/1): רעיונות ← בתכנון ← בעבודה ← הושלם.
3. **כל שינוי נבנה בענף נפרד** (למשל `feature/habits`), כך שהאפליקציה בטלפון ממשיכה לעבוד.
4. **בסוף נפתחת בקשת מיזוג (Pull Request)**. אחרי בדיקה ואישור, השינוי ממוזג ל-`main` ומגיע לטלפון תוך דקה.
5. **כל עדכון משמעותי מסומן כגרסה** ב-[Releases](https://github.com/roeokabe/matzpen/releases).
